# ТЕПЛО — электронный подарочный сертификат

Интерактивный React-макет страницы оформления электронного сертификата.

## Возможности

- выбор одного из четырёх дизайнов сертификата;
- выбор номинала от 1 000 до 10 000 ₽ (по умолчанию 5 000 ₽);
- ввод телефона получателя;
- имя и личное поздравление;
- экран итоговой проверки;
- плавные переходы между шагами, анимация выбранного дизайна и наклон карточки с синей подложкой;
- адаптивная компоновка для мобильных экранов.

> Это демонстрационный интерфейс: реальной оплаты и отправки сертификата нет.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm start
```

Webpack Dev Server откроет сайт в браузере.

## Сборка

```bash
npm run build
```

Готовая сборка создаётся в `docs/`. Эту папку можно публиковать через GitHub Pages.

## GitHub Pages

В репозитории откройте **Settings → Pages**, выберите источник публикации из ветки и папку `/docs`, затем сохраните настройки. После сборки и отправки изменений в GitHub Pages будет доступна опубликованная страница.

## Структура

- `src/javascripts/index.js` — React-компоненты и состояние мастера;
- `src/stylesheets/style.css` — визуальный стиль, адаптивность и анимации;
- `src/assets/` — изображения карточек и синей подложки;
- `src/index.html` — HTML-шаблон;
- `config/webpack.common.js` и `config/webpack.prod.js` — конфигурация сборки.
